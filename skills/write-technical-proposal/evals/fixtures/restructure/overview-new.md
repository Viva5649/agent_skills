# 文档引擎技术方案

## 1. 总体架构

引擎提供文档渲染与文本向量化。阅读应用、资料应用和搜索应用为消费方。

## 2. 场景方案

### 2.1 预览生成和归档转换

设备 A 的渲染吞吐为 40 份/分钟，内存为 PSS 周期采样均值 1000 MiB。本期目标：吞吐 ≥ 48 份/分钟，内存均值 ≤ 900 MiB。

### 2.2 语义检索

搜索应用已调用本地文本向量化，负责索引及排序；引擎返回向量。本期不做新旧向量兼容性验证。业务评测集未就绪。
