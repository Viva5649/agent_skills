# 文档引擎方案

## 接口与处理

阅读应用、资料应用调用 `render()`。搜索应用调用 `encode()`。
一次 encode 可输入多项文本，返回相同数量的结果，按输入顺序排列；单项失败仍返回其他成功项，失败项保留错误。

## 模型包切换

目标包就绪后切换新请求。目标包准备失败时继续使用当前包。准备期间保持当前包服务请求。

## 本期工作

渲染吞吐提高 10%，内存降低 5%。本期建设新旧向量兼容性验证，完成搜索索引迁移。引擎建设搜索应用的索引。

## 指标与诊断

进程内存基线为 PSS 周期采样均值 1000 MiB。
`trace_id` 关联同一业务任务，`operation_id` 定位一次引擎执行。运维先按 `trace_id` 找到相关操作，再选择失败的 `operation_id` 查看详情。
