# 创作者信号筛选规则

## 核心原则

每条入选内容至少满足一种价值：

1. 执行价值，能立刻试。
2. 判断价值，能提升理解。
3. 机会价值，能提示副业、产品或市场机会。

如果三者都不满足，排除。

## A. AI 实操

适合内容：

1. 工具、插件、App 或模型用法。
2. 工作流、自动化流程、内容生产流程。
3. Prompt、模板、教程、步骤拆解。
4. 可迁移的方法或最佳实践。

每条必须写清：

1. 核心方法是什么。
2. 现在可以怎么试。
3. 为什么值得保存。

## B. 副业思路

适合内容：

1. 一人公司案例。
2. 副业产品、服务、模板或内容产品。
3. 用户需求洞察。
4. 变现、获客、定价、分发、包装方式。
5. 能迁移到用户自己的内容、工具或产品实验中的机会。

每条必须写清：

1. 机会信号是什么。
2. 可能的变现角度是什么。
3. 需要警惕的限制是什么。

## C. 认知探索

适合内容：

1. 对 AI、创作、工作方式或个人能力的清晰观点。
2. 可复用判断框架。
3. 对常见误区的纠正。
4. 对长期选择或能力结构的解释。

排除：

1. 单句感慨。
2. 纯鸡汤。
3. 没有新解释的情绪表达。

每条必须写清：

1. 核心观点是什么。
2. 它改变了什么理解。
3. 适合在哪类场景使用。

## D. AI 趋势分析

适合内容：

1. 模型能力变化。
2. 产品格局变化。
3. 平台规则变化。
4. 创作者生态变化。
5. 工具链或用户行为变化。
6. 对未来 1 到 3 个月有观察价值的信号。

每条必须写清：

1. 趋势信号是什么。
2. 接下来可能发生什么。
3. 为什么值得继续看。

## 主栏目归属

一条内容可以内部拥有多个标签，但最终只进入一个主栏目。

主栏目选择顺序：

1. 最强价值是马上可试，放入 AI 实操。
2. 最强价值是机会发现，放入副业思路。
3. 最强价值是理解框架，放入认知探索。
4. 最强价值是生态变化，放入 AI 趋势分析。
5. 横跨多个栏目时，放入最稀缺、最能解释其价值的栏目。

## 默认排除

排除以下内容：

1. 纯情绪表达。
2. 无新信息的转发。
3. 只有融资、估值、发布会口号，没有个人行动或判断价值。
4. 纯 benchmark，除非它明显改变工具选择或趋势判断。
5. 只有产品宣传，没有具体用法、变化、机会或判断。
6. 与 AI、创作、副业、认知、产品机会、趋势观察都无关的日常内容。

## 质量门槛

每条入选内容都要能回答：

1. 为什么现在值得看？
2. 它对用户有什么启发？
3. 它应该被放进哪个栏目？
4. 后续应该行动、观察，还是沉淀为知识？
