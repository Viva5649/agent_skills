# 横纵分析与独立事实核查

完整复用 `hv-analysis` 的研究流程，只覆盖输出格式，并在完整初稿之后追加独立核查与修复。不得拆解、重组或另写一套研究方法。

## 加载原技能与覆盖边界

主 agent 从当前环境的技能清单定位并完整读取 `hv-analysis/SKILL.md`；用户指定路径时优先使用该路径。清单无记录时检查当前技能安装目录中的 `hv-analysis`。仍找不到时报告缺失，停止依赖它的研究，不凭记忆重建原技能。

开始研究前，主 agent 确认联网工具和支持独立新上下文的子 agent 工具可用；缺失时按末节报告阻塞，不先执行依赖这些能力的研究。

执行原技能前应用以下覆盖，其他要求全部保留：

- 研究报告及核查交付物只保存为标准 Markdown。
- 跳过 PDF 环境检查、依赖安装、转换脚本、PDF/中间排版 HTML 生成及 PDF 排版质检。用 Markdown 标题和元信息承载原封面信息，保留目录、章节、引用、来源 URL、访问时间及方法论说明。
- 保留原技能的研究准备、联网信息收集与子 agent 分工、纵向分析、横向分析、横纵交汇、对象适配、写作风格、全部字数要求及非 PDF 质检。本包装层不放宽篇幅要求。
- 原技能使用的工具名映射到当前环境中用途相同的工具；工具适配不改变研究要求。

本 Skill 上述输出约束覆盖原技能的对应要求。原技能中的交付动作延后到下述核查修复完成，不将初稿作为最终报告交付。

## 主 agent 完成初稿

主 agent 按原技能执行研究与写作，完成原技能的非 PDF 自检。按用户指定位置保存；未指定时，在用户工作目录创建本次研究目录，例如 `[研究对象]_横纵分析_YYYY-MM-DD/`，重名时加数字后缀，避免覆盖既有成果。不要把报告存入技能安装目录。

主 agent 保存 `初稿.md`，注明研究范围和信息截止日期；保留原技能要求的来源清单。初稿完成后固定内容，核查期间无人修改。后续修复写入另一份文件。

## 两个 agent 独立核查

主 agent 在初稿完成后新建核查 agent A 和 B，使用独立新上下文（工具支持时指定 `fork_turns="none"`），不复用参与研究或写作的 agent。两人并行核查同一份完整初稿，不按章节拆分。

主 agent 向两人分别提供：

- 相同的初稿绝对路径、研究对象与范围、信息截止日期、来源清单。
- 本节完整核查要求、当前可用联网工具和各自唯一可写的报告绝对路径：`核查报告-A.md` 或 `核查报告-B.md`。
- 独立性和写入边界：不传递写作者的推理、预设问题或其他核查结论；两人不得互相通信或读取对方报告。告知两人共享工作目录，仅能写自己的报告，不得改写初稿、其他成果或回退他人的改动。

两名核查 agent 各自联网读取原始来源，并独立寻找必要的补充证据。不得只复述初稿的来源清单或搜索摘要。按照研究截止日期核查事实，不能把截止日期之后的变化当成初稿错误。

每人检查完整初稿中的日期、数字与统计口径、人物、版本、引用支持程度、对比条件是否一致、因果和动机的证据，以及用户口碑是否被过度概括。区分事实错误、证据不足与明确标注的合理推断；核查推断的事实前提和支持范围，不因其不是确定事实就要求删除。

每份核查报告包含：

1. **核查范围与限制**：实际检查的章节和事实范围、无法访问的来源、尚未完成的检查。不得把抽查描述为全文事实验证。
2. **发现清单**：每条使用 `A-1` 或 `B-1` 等编号，写明章节及原文摘录、问题类型、理由、证据 URL 及页内定位/简短摘录、来源日期与访问日期、建议修改。未找到证据时明确说明，不伪造反证。
3. **核查结论**：允许无发现，但只能表述为“在已核查范围内未发现问题”，不能声称全部信息已证实。

两人各自检查完整初稿并记录发现与限制后，核查任务才算完成。检查后仍缺乏证据的陈述作为“证据不足”交 C 裁定，不等于任务未完成；因中断或资源限制而尚未检查的章节或事实范围属于未完成检查，主 agent 须让对应 agent 补齐后再交 C。

## 第三个 agent 裁定并修复

主 agent 等待两份核查报告完成后，新建第三个独立 agent C，同样使用新上下文，不复用研究、写作或 A/B 的 agent。

主 agent 给 C 提供原技能路径、本 Skill 的覆盖边界与本节要求、研究范围与截止日期、初稿和两份核查报告的绝对路径、联网工具，以及两个可写文件的绝对路径：`裁定与修订记录.md`、`最终报告.md`。不提供主 agent 的倾向性裁定。告知 C 保留初稿与 A/B 报告，不修改或回退其他文件。

C 读取输入并完成以下工作：

1. 合并重复发现，保留 A/B 原编号的对应关系；逐条重新查看证据，必要时补充取证。两人结论一致或多个网页转载同一来源，都不能代替原始证据。
2. 对每条发现裁定“采纳／驳回／无法判定”，在裁定记录中列明理由、证据和处理结果。仅一人提出的问题也必须裁定。
3. 从初稿生成最终报告，修复确认的事实错误；对证据不足的陈述补证、收窄、明确标注不确定性或删除。不得把“无法判定”写成已证实；会影响核心结论的未决问题须在最终报告中明确披露。
4. 修正关键事实时，同时检查并修复依赖它的横向比较、交汇洞察和未来推演。新增或替换的事实必须有来源，同步维护最终报告的来源清单。保持原技能的结构、研究方法、写作和篇幅要求，不作无关重写，也不为凑字数制造事实。
5. 复查修改处及其关联结论是否与证据一致，在裁定记录中标明最终报告位置、实际修复及剩余限制；意外发现的新问题也记录证据与处理结果。

## 完成与交付

默认只执行一轮双人核查和一轮裁定修复；C 完成必要的改动复查，不自动重启整轮核查。主 agent 核对五份文件齐全、A/B 每条发现均有裁定、采纳的问题已处理、未决问题已披露，并检查最终报告仍符合原技能的非 PDF 质量与字数要求。发现漏项时交回对应负责人补齐，不能把未完成状态称为完成。

主 agent 交付 `最终报告.md`，同时链接 `初稿.md`、`核查报告-A.md`、`核查报告-B.md` 和 `裁定与修订记录.md`。简述修复情况和剩余限制，不承诺事实绝对准确。

联网工具、独立子 agent 能力不可用，或任一核查任务未完成时，主 agent 保留已完成文件并明确报告阻塞阶段；不能自行扮演三名独立 agent、编造报告或将未核查初稿标为最终报告。
