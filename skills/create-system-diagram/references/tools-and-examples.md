# 工具与布局示例

新建布局、编写生成脚本或运行几何检查时读取本文件。工具只使用 Python 3 标准库，不安装依赖，不启动浏览器。模板与示例均默认浅色，保留深色样式。

## 选择可编辑的骨架

| 示例 | 适用问题 | 复用内容 |
| --- | --- | --- |
| [连续分层](../assets/examples/layered.html) | 公开能力、编排与基础设施之间有什么关系 | 共同边界、层内卡片、直接通道、编号加两行标签 |
| [并列工作流](../assets/examples/parallel.html) | 不同任务各由谁处理、产生什么 | 工作流分组、同类基线、短交接线，职责颜色不按行轮换 |
| [局部回路](../assets/examples/loop.html) | 检查结果如何决定交付或返回修正 | 正常路径与条件回路分开，回路有完整直线接入段 |

示例只描述通用绘图场景，使用时替换标题、节点、关系、条件与图注。没有事实依据的默认关系必须删除；示例中允许返回修正，不代表实际项目也允许重试。组件多于示例时，调整布局或拆图，不能截取前几项或隐藏正文。

示例由 [render_examples.py](../scripts/render_examples.py) 生成。脚本从 [architecture-template.html](../assets/architecture-template.html) 读取 CSS、页面结构和 marker，避免维护另一套色板。需要重新生成时，在 Skill 目录运行：

```bash
python3 scripts/render_examples.py --outdir /tmp/architecture-examples
# 也可只生成一种：--layout layered、parallel 或 loop
```

目标文件已经存在时，脚本拒绝覆盖。维护者在新目录生成并比较后，只替换确认需要更新的包内示例。产物可独立打开，运行时不依赖生成脚本。

## 复用坐标计算

生成脚本中的节点记录包含 ID、矩形位置与尺寸、职责类及文字。`port(box, side)` 从矩形求边界端点；`edge(...)` 用端点和明确的中间点生成路径。`label_anchor(...)` 从最长线段选择候选位置，水平线在上方居中，竖线按指定侧对齐。移动节点后重新计算端点与标签，不再分别手写三套坐标。

这些函数是可复制修改的示例，不是任意图的布局求解器。分组、列宽、主路径、回路顺序和中间点仍由绘图代理根据图意安排。多回路须统筹长短顺序，分配不同通道仍可能交叉。两行标签按整体定位；候选位置与标题、卡片或其他线冲突时，调整位置并复看，不机械采用最长线段的中点。

## 运行只读检查

```bash
python3 scripts/check_diagram.py <图文件.html>
```

输入可以是含内嵌 SVG 的 UTF-8 HTML，也可以是独立 SVG。工具不改输入，输出 JSON；发现 `error` 时退出码为 `1`，否则为 `0`。诊断包含 `code`、`severity`、`path`、`message`、`fix`，必要时包含交点或距离。`path` 使用 SVG 序号与元素 ID 定位问题，无 ID 时退回元素位置。

| 自动检查 | 范围与判断 |
| --- | --- |
| SVG 与引用 | XML 结构、viewBox、文件内重复 ID、marker 与可访问名称引用 |
| 卡片 | `rect.card`、`rect.mini` 的越界与相互覆盖；分组外框不当成组件卡片 |
| 连线 | 带 `edge` 类的绝对 `M/L/H/V` 路径、正交 `polyline` 和 `line`；检查越界、穿卡片及不同连线内部交叉 |
| 共用通道 | 共线重叠作为警告，交点恰为线段端点的接触仍需人工检查；有意汇合应明确拆分到共同端点 |
| 箭头末段 | 带 `marker-end` 的折线末段短于阈值时提示；不测量实际 marker 的像素轮廓 |
| 标签锚点 | 按 `data-edge-label` 绑定的连线计算距离，检查空标签；距离不等于真实文字边界或可读性 |

为连线设置 ID，为每个标签文字绑定对应连线；多行共享同一连线 ID。图例使用 `data-legend="true"`，避免误报为缺少关系绑定：

```html
<path id="read-config" class="edge k-plain" d="M350,504 V640" />
<text class="edge-label k-plain" data-edge-label="read-config"
      x="366" y="570">读取通用配置</text>
```

没有绑定的标签会报告 `unbound_label`，不会通过猜测把最近的箭头当作目标。现有图可先运行检查，再补充受影响标签的绑定，不必为了局部修改重写整张图。

末段长度提示默认 `18`、标签锚点距离提示默认 `48`，单位均为 SVG 用户单位。它们是筛查起点，可用 `--min-entry`、`--max-label-distance` 调整；改变阈值须符合实际字号和显示比例，不能只为消除警告。

**检查结果必须连同覆盖范围阅读。** `ok: true` 只表示支持范围内没有检出的错误。`coverage` 列出 SVG、连线、已检查连线与标签数量，以及跳过项。曲线、相对路径、坐标变换等未支持内容会提示跳过。CSS 覆盖几何、嵌套 SVG、真实文字边界、字形回退、穿字、标签语义和背景避让不在自动检查范围内；这些内容见输出的 `manual_checks`，继续用真实渲染复核。

## 维护时验证

```bash
python3 -B -m unittest discover -s tests -v
```

[测试](../tests/test_diagrams.py) 覆盖交叉回路、共线重叠、有意汇合、短促折弯、穿卡片、标签偏移、引用错误、未支持几何的披露、坐标随节点移动，以及三个示例的结构检查。修改共享样式或生成脚本后，重新生成示例，对照明暗主题并检查实际显示尺寸；不能只更新生成的 HTML。

另用下列输入做视觉与语义复核，机器检查不能代替这些判断：

| 输入变化 | 应验证的结果 |
| --- | --- |
| 把分组标题移到竖直主线处 | 调整标题或通道，保留清楚的直线关系，不用底色遮住穿字 |
| 将两行标签移到相邻另一条线附近 | 标签仍能唯一对应所属连线；机器距离通过也要复看 |
| 将「R1 · 提交查询」改成只有「R1」或 API 名 | 恢复动作与对象，编号含义明确，主要内容无需查表 |
| 增加很长的中文组件名、英文标识和必要条件 | 内容完整、实际字号可读；扩大、换行或拆图，不隐藏正文或自动缩字 |
| 增加第二条返回不同目标的回路 | 统筹端口与通道顺序；独立通道不作为无交叉的证明 |

只有用户请求时才增加其他输出格式。浏览器或离线渲染不可用时披露缺口，不以结构检查通过宣称完成视觉验证。
